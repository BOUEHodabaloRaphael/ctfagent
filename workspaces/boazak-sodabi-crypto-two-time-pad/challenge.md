## Description

Origine du nom : Sodabi est l'eau-de-vie de palme du Togo, un alcool fort qu'on aime partager entre amis — ici, c'est la même clé XOR qui a été partagée entre deux messages. Deux messages ont été chiffrés avec le même masque jetable (réutilisé). Le premier est le flag, le second... un texte tout public, fourni avec les chiffrés. Retrouvez le flag dans challenge.txt.
